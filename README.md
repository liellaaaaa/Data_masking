# Excel 数据脱敏工具

本地运行的数据脱敏工具，支持 Excel/CSV 文件的敏感信息脱敏处理。所有数据处理均在本地完成，不会上传到任何外部服务器。

## 功能特点

- **12种脱敏方法**：姓名、身份证号、手机号、银行卡号、地址、邮箱、公司名、自定义文本、随机数字、部分遮蔽、完全遮蔽、保留格式遮蔽
- **智能推荐**：根据列名自动推荐脱敏规则
- **映射表加密**：支持密码加密映射表，保护原始数据对照关系
- **多编码支持**：自动检测 CSV 文件编码（UTF-8/GBK/GB2312/Latin-1）
- **数据还原**：通过映射表可将脱敏数据还原为原始数据

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动工具

```bash
# Windows
启动.bat

# 或直接运行
streamlit run mask_tool.py
```

浏览器打开 http://localhost:8501

## 使用流程

1. 上传 Excel 或 CSV 文件
2. 预览数据，选择要脱敏的列
3. 为每列选择脱敏方法
4. 点击「开始脱敏」
5. 下载脱敏后文件和映射表

## 安全说明

- 所有数据处理均在本地完成
- 映射表包含原始数据对照关系，建议加密保存
- 不要通过邮件/即时通讯工具发送映射表
